# 利用ログと管理画面のセットアップ

アプリ（`index.html`）が利用ログを送り、Google スプレッドシートに溜め、管理者だけが見られる管理画面で集計を見る仕組み。
サーバー代は 0 円。必要なのは管理者の Google アカウントだけ。

```
アプリ（各端末） ──ログ──▶ ① 受け取り係（Apps Script・誰でも送れる）──▶ スプレッドシート「log」
                                                                            │
管理者のブラウザ ◀── ② 管理画面（Apps Script・自分のみ・Google ログイン必須）◀──┘
```

## 記録する内容（これだけ）

| 列 | 中身 |
|---|---|
| 受信日時 | Google 側で受け取った時刻 |
| 端末ID | 端末のブラウザで最初に開いたときに作るランダムな番号（`localStorage` の `kara-device`） |
| 種類 | `open`＝アプリを開いた ／ `play`＝1回の再生が終わった・止めた・再生中にページを閉じた |
| 再生秒数 | `play` のときだけ。実際に流れた秒数（カウントの4拍は除く） |

- 曲・パート・点数・名前・声・IP アドレスは記録しない
- 送信は**アプリから一方通行**。利用者側にログイン・許可ダイアログ・設定は一切ない（ブラウザが裏で送るだけ）
- 静的サイトのホスティング（GitHub Pages など）は書き込みを受け付けられないため、受け取り口だけ Google に置いている

## 管理画面で分かること

- 使った端末数、1日あたりの端末数（平均）、1台あたりの利用日数、合計練習時間
- 利用頻度の分布：期間中に「1日だけ／2〜3日／4〜7日／8〜14日／15日以上」使った端末が何台か
- 週別・日別の端末数（うち初めて来た端末）・開いた回数・練習時間

## セットアップ（1回だけ・15分ほど）

### 1. スプレッドシート（作成済み）
Google ドライブのマイドライブに「カラオケ利用ログ」として作成済み（シート名 `log`、見出し行あり、タイムゾーンは日本時間）。
URL: https://docs.google.com/spreadsheets/d/1Jq3boKjYm0pzK9tzxSRCb0NPNiTNahLi7TLwpS7DO0k/edit
共有はしない。

### 2. ① 受け取り係を公開する
1. そのスプレッドシートで［拡張機能］→［Apps Script］
2. 最初からある中身を消し、`admin/collector.gs` の中身を全部貼って保存
3. 右上の［デプロイ］→［新しいデプロイ］→ 種類「ウェブアプリ」
   - 実行ユーザー：**自分**
   - アクセスできるユーザー：**全員**
4. ［デプロイ］→ 権限の確認画面で自分のアカウントを選んで許可（「確認されていません」と出たら［詳細］→［（プロジェクト名）に移動］）
5. 表示された **ウェブアプリの URL（…/exec）** を控える

### 3. アプリに URL を入れる
`logging.js` の 5 行目 `const LOG_URL="";` の `""` の中に、2-5 の URL を貼ってコミット・公開する。
（Claude Code に「この URL を入れて」と渡せば代わりにやります）

### 4. ② 管理画面を公開する
1. https://script.google.com で［新しいプロジェクト］（スプレッドシートからではなく、単独で作る）
2. 中身を消して `admin/dashboard.gs` を貼って保存（`SHEET_ID` は記入済み）
3. ［デプロイ］→［新しいデプロイ］→「ウェブアプリ」
   - 実行ユーザー：**自分**
   - アクセスできるユーザー：**自分のみ**
4. 許可して、表示された URL を**ブックマーク**する。これが管理画面

管理画面の URL の末尾に `?days=7` `?days=90` `?days=0`（全期間）を付けると期間が変わる（既定は 30 日）。

## 管理画面が見られるのは誰か

- ②は「自分のみ」で公開しているため、URL を知っていても、**あなたの Google アカウントでログインしていない人には開けない**
- ①は誰でもログを**送れる**が、**読み出す機能は持たない**。シートそのものも共有しない限りあなたしか開けない
- 生のログはスプレッドシートの「log」シートでも見られる

## 自分の試し弾きを数に入れたくないとき

アプリを一度 `…/index.html?nolog` で開くと、その端末からはログを送らなくなる。`?log` で開けば元に戻る。

## 数字の読み方（限界）

- **端末数 ≠ 人数。** 同じ人がスマホと PC で使えば 2、Safari の履歴やサイトデータを消したり、プライベートブラウズで開いたりしても別の端末として数える（多めに出る）。逆に1台を家族で使い回すと 1（少なめに出る）
- ①の URL を知っている人は、形式の合ったデタラメなログを送れる（アプリのページを見れば URL は分かる）。合唱練習の利用状況を見る用途なら実害は小さいと判断したが、数字が不自然に跳ねたら疑う
- 再生中にスマホのホーム画面へ戻っただけ（ページを閉じていない）の場合は、その後に止めるかページを閉じるまで送られない
- 送信に失敗したログは捨てる（再送しない）。電波の悪い場所の利用は少なめに出る

## コードを直したとき

Apps Script はコードを保存しただけでは公開中の URL に反映されない。
［デプロイ］→［デプロイを管理］→ 鉛筆アイコン → バージョン「新バージョン」→［デプロイ］で、**同じ URL のまま**更新する。
（［新しいデプロイ］にすると URL が変わり、アプリ側の `LOG_URL` も直す必要がある）
